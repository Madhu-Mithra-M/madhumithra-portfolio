# Madhumithra M – Portfolio

A modern, responsive personal portfolio showcasing my projects, technical skills, patent publication, achievements, certifications, and coding profiles. Built with React, TypeScript, Vite, and Tailwind CSS.

## 🚀 Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## ✨ Features

- Responsive design for desktop and mobile
- Smooth animations and modern UI
- Project showcase with GitHub and live demo links
- Patent publication section
- Skills, achievements, and certifications
- Coding profiles
- Resume download
- Contact section with social links

## 🛠️ Getting Started

Clone the repository:

```bash
git clone https://github.com/Madhu-Mithra-M/madhumithra-portfolio.git
```

Navigate to the project:

```bash
cd madhumithra-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
